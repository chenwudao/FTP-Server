Detailed Description

FTP服务器，基于ACE Reactor事件驱动模型

职责：

  • 初始化并监听控制连接端口（默认21）
  • 接受客户端连接请求（handle_input回调）
  • 为每个客户端创建FTPConnection对象并注册到Reactor
  • 管理全局配置（根目录、用户密码文件等）
  • 运行Reactor事件循环

使用方式：

FTPServer server;
if (server.open(21, "/var/ftp") == 0) {
server.run(); // 进入事件循环
}
