Detailed Description

表示单个FTP客户端会话

职责：

  • 维护客户端认证状态、工作目录等会话信息
  • 处理控制连接上的命令输入（handle_input）
  • 解析命令并分发给对应的Command对象
  • 管理DataConnection（PASV模式）
  • 发送FTP响应到客户端

生命周期：

  • 由FTPServer在accept新连接时创建
  • 注册到Reactor监听控制连接socket
  • 收到QUIT或连接断开时销毁
