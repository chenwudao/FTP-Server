\doxysubsection{Detailed Description}
F\+T\+P命令接口，所有命令实现必须继承此接口 

提供统一的命令执行接口，支持多态分发。 每个具体命令（如\+U\+S\+E\+R、\+P\+A\+S\+S、\+L\+I\+S\+T等）实现execute方法。
