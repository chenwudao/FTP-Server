\doxysubsection{Detailed Description}
F\+T\+P服务器，基于\+A\+CE Reactor事件驱动模型 

职责：
\begin{DoxyItemize}
\item 初始化并监听控制连接端口（默认21）
\item 接受客户端连接请求（handle\+\_\+input回调）
\item 为每个客户端创建\+F\+T\+P\+Connection对象并注册到\+Reactor
\item 管理全局配置（根目录、用户密码文件等）
\item 运行\+Reactor事件循环
\end{DoxyItemize}

使用方式： 
\begin{DoxyCode}{0}
\DoxyCodeLine{\mbox{\hyperlink{classftpd_1_1FTPServer_aa866441e85b35971c23e82770f882a8e}{FTPServer}} server;}
\DoxyCodeLine{\textcolor{keywordflow}{if} (server.open(21, \textcolor{stringliteral}{"/var/ftp"}) == 0) \{}
\DoxyCodeLine{    server.run();  \textcolor{comment}{// 进入事件循环}}
\DoxyCodeLine{\}}
\end{DoxyCode}
