\doxysubsection{Detailed Description}
表示单个\+F\+T\+P客户端会话 

职责：
\begin{DoxyItemize}
\item 维护客户端认证状态、工作目录等会话信息
\item 处理控制连接上的命令输入（handle\+\_\+input）
\item 解析命令并分发给对应的\+Command对象
\item 管理\+Data\+Connection（\+P\+A\+S\+V模式）
\item 发送\+F\+T\+P响应到客户端
\end{DoxyItemize}

生命周期：
\begin{DoxyItemize}
\item 由\+F\+T\+P\+Server在accept新连接时创建
\item 注册到\+Reactor监听控制连接socket
\item 收到\+Q\+U\+I\+T或连接断开时销毁 
\end{DoxyItemize}
