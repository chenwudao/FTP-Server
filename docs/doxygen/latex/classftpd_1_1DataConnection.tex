\doxysubsection{Detailed Description}
处理\+F\+T\+P被动模式（\+P\+A\+S\+V）数据传输 

负责：
\begin{DoxyItemize}
\item 创建随机端口监听器并注册到\+Reactor
\item 接受客户端数据连接
\item 发送数据（\+L\+I\+S\+T、\+R\+E\+T\+R）
\item 接收数据（\+S\+T\+O\+R）
\item 传输完成后关闭连接
\end{DoxyItemize}

使用场景：
\begin{DoxyEnumerate}
\item 收到\+P\+A\+S\+V命令时创建\+Data\+Connection对象并调用pasv\+\_\+listen()
\item 返回\char`\"{}227 Entering Passive Mode (h1,h2,h3,h4,p1,p2)\char`\"{}
\item 客户端连接后，handle\+\_\+input被触发，accept数据连接
\item 后续\+L\+I\+S\+T/\+R\+E\+T\+R/\+S\+T\+O\+R命令通过send\+\_\+data/recv\+\_\+data传输数据
\item 传输完成调用close() 
\end{DoxyEnumerate}
